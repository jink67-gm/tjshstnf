# 서·논술형 평가 연습실

초등 교원 서·논술형 평가 연수용 연습 웹앱입니다.

- **같은 답안, 같은 점수? (실시간)**: 진행자가 방을 만들고 참여자가 방 번호로 들어와 같은 학생 답안을 함께 채점합니다. 모호한 기준표(1차)와 구체적인 기준표(2차)의 채점 일치도를 비교합니다.
- **문항 검토 클리닉**: 사회과 문항을 보고 가장 먼저 고쳐야 할 점을 진단한 뒤 해설과 수정 예시를 확인합니다.
- **기준 문장 다듬기**: 판단이 갈리는 채점기준 문장을 누가 채점해도 같은 점수가 나오는 문장으로 고쳐 씁니다.

## 설정
1. Firebase 콘솔에서 Firestore Database를 만듭니다.
2. Firestore 규칙에 `firestore.rules` 내용을 붙여 넣고 게시합니다.
3. GitHub Pages(Settings → Pages → main 브랜치, / (root))로 배포합니다.
